# Quiz de Tecnologia

**Nome do projeto:** Quiz de Tecnologia

**Integrante:** Valcir Viana Galvão

**Trilha:** Desenvolvimento Mobile

Um jogo de perguntas e respostas sobre tecnologia, desenvolvido em Dart, com diferentes níveis de dificuldade e sistema de pontuação.

## Sobre o projeto

O Quiz de Tecnologia foi desenvolvido como um projeto de aprendizado em Dart, com o objetivo de praticar conceitos fundamentais de programação por meio de um jogo interativo no terminal.

O jogador informa seu nome, escolhe o nível de dificuldade e responde a cinco perguntas sobre tecnologia. Ao final, recebe sua pontuação e pode conferir o ranking da sessão.

## Funcionalidades

- Cadastro do nome do jogador.
- Três níveis de dificuldade: Fácil, Médio e Difícil.
- Perguntas de múltipla escolha.
- Sistema de pontuação.
- Resultado final com quantidade de acertos.
- Ranking dos jogadores.
- Salvamento do ranking em arquivo de texto.
- Opção de iniciar uma nova partida.

## Tecnologias utilizadas

- Dart
- Biblioteca `dart:io` para entrada e saída de dados e manipulação de arquivos.
- Biblioteca `dart:math` para recursos matemáticos e aleatoriedade.
